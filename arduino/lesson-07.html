Ders 7: LDR (Işık Sensörü)

Orta

LDR (Light Dependent Resistor) kullanarak ortam ışığını algıla ve LED'i kontrol et.

📚 Öğrenecekleriniz

  • LDR (fotoresistor) nedir
  • Işık şiddeti ölçümü
  • AnalogRead ile sensör verileri
  • Eşik değeri (threshold) ayarlama
  • Otomatik gece lambası yapımı

💻 Arduino Kodu

// LDR Işık Sensörü - Ders 7

int ldrPin = A0;   // LDR - Analog Pin
int ledPin = 9;    // LED - PWM Pin
int lightValue = 0;
int threshold = 300;  // Eşik değeri

void setup() {
  pinMode(ledPin, OUTPUT);
  Serial.begin(9600);
}

void loop() {
  // LDR'den değer oku (0-1023)
  lightValue = analogRead(ldrPin);
  
  // Işık düşükse LED'i yak
  if (lightValue < threshold) {
    digitalWrite(ledPin, HIGH);  // LED açık
  } else {
    digitalWrite(ledPin, LOW);   // LED kapalı
  }
  
  // Seri monitöre yazdır
  Serial.print("Işık: ");
  Serial.println(lightValue);
  
  delay(500);
}
