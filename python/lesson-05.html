Ders 5: Karşılaştırma Operatörleri

Kolay

Değerleri karşılaştırarak True veya False sonucu elde ederiz.

📚 Öğrenecekleriniz

  • Eşittir (==)
  • Eşit değildir (!=)
  • Büyüktür (>)
  • Küçüktür (<)
  • Büyük veya eşit (>=)
  • Küçük veya eşit (<=)

💻 Örnekler

# Karşılaştırma Operatörleri

a = 10
b = 5

# Eşittir (==)
print(a == b)    # False
print(a == 10)   # True

# Eşit değildir (!=)
print(a != b)    # True
print(a != 10)   # False

# Büyüktür (>)
print(a > b)     # True (10 > 5)
print(5 > 10)    # False

# Küçüktür (<)
print(a < b)     # False (10 < 5 değil)
print(5 < 10)    # True

# Büyük veya eşit (>=)
print(a >= 10)   # True
print(a >= 11)   # False

# Küçük veya eşit (<=)
print(b <= 5)    # True
print(b <= 4)    # False
