Ders 8: String'ler ve String Metodları

Kolay

Metinlerle çalışan güçlü metotları öğrenelim. upper(), lower(), replace(), split() ve daha fazlası!

📚 Öğrenecekleriniz

  • String metodları
  • upper() - Büyük harfe çevir
  • lower() - Küçük harfe çevir
  • replace() - Değiştir
  • split() - Böl
  • join() - Birleştir
  • strip() - Boşluk kaldır
  • find() - Bul
  • count() - Saç

💻 Örnekler

# String Metodları

metin = "Merhaba Dünya!"

# upper() - Büyük harfe çevir
print(metin.upper())  # MERHABA DÜNYA!

# lower() - Küçük harfe çevir
print(metin.lower())  # merhaba dünya!

# len() - Uzunluk
print(len(metin))  # 14

# replace() - Değiştir
print(metin.replace("Dünya", "Python"))  # Merhaba Python!

# split() - Böl
sozler = metin.split()  # ['Merhaba', 'Dünya!']
print(sozler)

# join() - Birleştir
sonuc = "-".join(sozler)  # Merhaba-Dünya!
print(sonuc)

# strip() - Boşluk kaldır
metin2 = "  Merhaba  "
print(repr(metin2.strip()))  # 'Merhaba'

# find() - Bul
indeks = metin.find("Dünya")
print(indeks)  # 8

# count() - Sayı
print(metin.count("a"))  # 2

# startswith() / endswith()
print(metin.startswith("Merhaba"))  # True
print(metin.endswith("!"))  # True
