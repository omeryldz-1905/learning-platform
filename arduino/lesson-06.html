Ders 6: Buzzer ile Ses Çıkart

Kolay

Buzzer (ses üreticisi) kullanarak çeşitli ses ve müzik notaları oluşturacağız.

📚 Öğrenecekleriniz

  • Buzzer'ın çalışma prensibi
  • tone() fonksiyonu ile frekans kontrolü
  • Müzik notalarının frekansları
  • Melodi oluşturma
  • Passive ve Active buzzer farkı

🔌 Devre Şeması

Arduino Pin 8 ---[Buzzer]---GND

NOT: Buzzer kutuplarına dikkat et!
(+ ve - ayırımı var)

💻 Arduino Kodu

// Buzzer ile Ses Çıkartma - Ders 6

int buzzerPin = 8;  // Buzzer PIN

// Müzik notalarının frekansları (Hz)
int DO = 262;      // C4
int RE = 294;      // D4
int MI = 330;      // E4
int FA = 349;      // F4
int SOL = 392;     // G4
int LA = 440;      // A4
int SI = 494;      // B4

void setup() {
  pinMode(buzzerPin, OUTPUT);
}

void loop() {
  // Müzik notalarını çal
  tone(buzzerPin, DO, 500);    // DO - 500ms
  delay(600);
  
  tone(buzzerPin, RE, 500);    // RE
  delay(600);
  
  tone(buzzerPin, MI, 500);    // MI
  delay(600);
  
  tone(buzzerPin, FA, 500);    // FA
  delay(600);
  
  tone(buzzerPin, SOL, 500);   // SOL
  delay(1000);
  
  noTone(buzzerPin);           // Sesi kapat
  delay(2000);
}

🎵 Müzik Notaları Frekansları

tone(pin, frekans, süre)

Belirtilen pin'den belirtilen frekansda ses üretir. Süre milisaniye cinsinden.

noTone(pin)

Belirtilen pin'deki sesi kapatır.
