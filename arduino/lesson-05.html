Ders 5: Potansiyometre ile LED Parlaklığı

Kolay

Potansiyometre (değiştirilebilir direnç) kullanarak LED'in parlaklığını kontrol edeceğiz.

📚 Öğrenecekleriniz

  • Analog giriş okuma (analogRead)
  • ADC (Analog-to-Digital Converter) nedir
  • Potansiyometre bağlantısı
  • Analog değeri dijital değere dönüştürme

💻 Arduino Kodu

int potPin = A0;    // Potansiyometre - Analog Pin 0
int ledPin = 9;     // LED - PWM Pin
int potValue = 0;   // Potansiyometre değeri
int ledBrightness = 0;  // LED parlaklığı

void setup() {
  pinMode(ledPin, OUTPUT);
}

void loop() {
  // Potansiyometreden değer oku (0-1023)
  potValue = analogRead(potPin);
  
  // 0-1023 değerini 0-255'e dönüştür
  ledBrightness = map(potValue, 0, 1023, 0, 255);
  
  // LED parlaklığını ayarla
  analogWrite(ledPin, ledBrightness);
  
  delay(50);
}
