Ders 4: Matematiksel Operatörler

Kolay

Python'da matematik işlemleri yapabiliriz. Toplama, çıkarma, çarpma, bölme ve daha fazlası!

📚 Öğrenecekleriniz

  • Toplama (+)
  • Çıkarma (-)
  • Çarpma (*)
  • Bölme (/)
  • Tam bölme (//)
  • Mod alma (%)
  • Üs alma (**)

💻 Örnekler

# Matematiksel Operatörler

# Toplama
num1 = 10
num2 = 5
toplam = num1 + num2
print(f"{num1} + {num2} = {toplam}")  # 15

# Çıkarma
fark = num1 - num2
print(f"{num1} - {num2} = {fark}")    # 5

# Çarpma
çarpim = num1 * num2
print(f"{num1} * {num2} = {çarpim}")  # 50

# Bölme (Ondalık sonuç)
bolum = num1 / num2
print(f"{num1} / {num2} = {bolum}")   # 2.0

# Tam bölme (Tamsayı sonucu)
tam_bolum = num1 // num2
print(f"{num1} // {num2} = {tam_bolum}")  # 2

# Mod (Kalan)
kalan = num1 % num2
print(f"{num1} % {num2} = {kalan}")   # 0

# Üs alma
kare = 5 ** 2
kup = 5 ** 3
print(f"5 ** 2 = {kare}")  # 25
print(f"5 ** 3 = {kup}")    # 125

# Sıralama (Öncelik)
sonuc = 2 + 3 * 4
print(f"2 + 3 * 4 = {sonuc}")  # 14 (çarpma önce)

# Parantez kullanımı
sonuc2 = (2 + 3) * 4
print(f"(2 + 3) * 4 = {sonuc2}")  # 20

🔍 Detaylı Açıklama

Bölme (/) vs Tam Bölme (//)

10 / 3 = 3.333... (ondalık) | 10 // 3 = 3 (tamsayı)

Mod (%)

Bölme işleminin kalanını verir. 10 % 3 = 1

Üs (**)

2 ** 3 = 2 * 2 * 2 = 8

İşlem Sırası

1. Parantez () 2. Üs ** 3. *, /, //, % 4. +, -
