# 🚀 Tech Academy - Öğrenme Platformu

Arduino, Python ve 3D Modelleme ile teknoloji öğrenin!

## 📚 Dersler

### Arduino (18 Ders)
- **Kolay (6 ders)**: LED, Buton, RGB LED, Ses
- **Orta (7 ders)**: Sensörler, Motor, Ekranlar
- **Zor (5 ders)**: WiFi, Bluetooth, IoT

### Python (25 Ders)
- **Kolay (10 ders)**: Temel konseptler, Operatörler, Döngüler
- **Orta (10 ders)**: Listeler, Fonksiyonlar, Dosyalar
- **Zor (5 ders)**: OOP, Dekoratörler, API

### 3D Modelleme
- Yakında geliyor...

## 🛠️ Nasıl Kullanılır?

1. Repository'yi klonla
2. VS Code'da açın
3. `index.html` dosyasını tarayıcıda aç
4. Dersleri sırayla takip et

## 📁 Klasör Yapısı

```
learning-platform/
├── index.html              # Ana sayfa
├── css/
│   ├── style.css          # Ana stillar
│   └── lesson.css         # Ders sayfaları stili
├── js/
│   └── script.js          # JavaScript fonksiyonları
├── arduino/
│   ├── lesson-01.html     # Ders sayfaları
│   └── code/
│       └── lesson-01.ino  # Arduino kodları
└── python/
    ├── lesson-01.html     # Ders sayfaları
    └── code/
        └── lesson-01.py   # Python kodları
```
