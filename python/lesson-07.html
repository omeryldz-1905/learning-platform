Ders 7: If/Elif/Else Koşullu İfadeler

Kolay

Koşullara göre farklı işlemler yapabiliriz. Karar ağaçları oluşturabiliriz!

📚 Öğrenecekleriniz

  • if ifadesi (eğer)
  • elif ifadesi (eğer değilse)
  • else ifadesi (yoksa)
  • İç içe koşullar
  • Karmaşık karar ağaçları

💻 Örnekler

# If/Elif/Else

# Basit if
yas = 20

if yas >= 18:
    print("Reşitsiniz")

# if/else
if yas >= 18:
    print("Reşitsiniz")
else:
    print("Henüz reşit değilsiniz")

# if/elif/else
not = 85

if not >= 90:
    print("A - Çok İyi")
elif not >= 80:
    print("B - İyi")
elif not >= 70:
    print("C - Yeterli")
elif not >= 60:
    print("D - Zayıf")
else:
    print("F - Başarısız")

# İç içe if
hava = "güneşli"
temperatur = 25

if hava == "güneşli":
    if temperatur > 20:
        print("Dışarıya çık ve oyna!")
    else:
        print("Dışarıya çık ama ceket giy!")
else:
    print("Evde kal!")
