Ders 6: Mantıksal Operatörler (and, or, not)

Kolay

Birden fazla koşulu birleştirerek daha karmaşık kararlar verebiliriz.

📚 Öğrenecekleriniz

  • and operatörü (ve)
  • or operatörü (veya)
  • not operatörü (değil)
  • Koşulları birleştirme

💻 Örnekler

# Mantıksal Operatörler

# AND (ve) - Her ikisi de True ise sonuç True
print(True and True)    # True
print(True and False)   # False
print(False and False)  # False

yas = 25
uzunluk = 180

# İkisi de True ise
if yas >= 18 and uzunluk >= 160:
    print("Roller coaster'a binebilirsin!")

# OR (veya) - En az biri True ise sonuç True
print(True or False)    # True
print(False or False)   # False

hava = "yağmurlu"
evi_var = True

# Birisi True ise
if hava == "yağmurlu" or evi_var:
    print("Şemsiye al veya evde kal!")

# NOT (değil) - Tersi
print(not True)    # False
print(not False)   # True

# Değili
if not False:
    print("Bu doğru!")
