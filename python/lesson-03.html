Ders 3: Giriş Alma (input)

Kolay

Kullanıcıdan veri almayı ve onu işlemeyi öğrenelim.

📚 Öğrenecekleriniz

  • input() fonksiyonu
  • Kullanıcı girdisini okuma
  • Girdiye tepki verme
  • Hata işleme

💻 Örnek Kodlar

# Basit giriş alma
adı = input("Adını gir: ")
print(f"Merhaba {adı}!")

# Yaş girişi
yemen = int(input("Yaşını gir: "))

# Matematik
num1 = float(input("1. sayıyı gir: "))
